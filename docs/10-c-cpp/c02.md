# C02 · 栈、堆、静态存储与对象生命周期怎么区分？

学习优先级：P0。先独立回答，再展开机制与验证。

## 直接回答

栈和堆是常见实现术语；C 语言层面应先讲自动、静态、线程与分配存储期。存储仍存在不代表其中某个对象仍处于有效生命周期，返回局部变量地址是经典错误。

## 原理拆解

自动对象在离开所属块后结束生命周期；静态对象跨程序执行期存在。malloc 得到分配存储，需有明确的释放责任。C++ 构造与析构进一步管理对象生命周期，裸字节空间不能无条件当作任意已经构造的对象。

## 例子与推演

```c
/* 错误：p 指向的对象已结束生命周期。不要运行来猜答案。 */
int *bad(void) { int value = 7; return &value; }
/* 正确方式之一：由调用方提供输出对象。 */
void read_value(int *out) { *out = 7; }
```
静态局部变量可解决生命周期，但会引入共享状态与重入问题。

## 常见误区与失败边界

不能承诺局部变量永远在栈上，优化可能消除它。内存泄漏与悬空指针不同：前者失去释放路径，后者仍持有无效地址。

## 面试追问

ISR 与任务都调用返回静态缓冲区的函数会怎样？答：可能互相覆盖，接口应传入缓冲区或明确串行化。

## 动手练习与验收

画出一段分配、传递、释放的所有权图，覆盖成功和失败路径。验收：每次分配恰有一条释放责任，所有返回地址有合法生命周期。
