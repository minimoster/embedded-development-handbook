# C13 · static、extern、声明与定义怎样区分？

学习优先级：P0。先独立回答，再展开机制与验证。

## 直接回答

声明介绍名字和类型，定义创建对象/函数实体。文件作用域 static 常提供内部链接；extern 常用于声明外部实体，但带初始化等情形可是定义。static 局部对象则是静态存储期，不等于文件内私有函数。

## 原理拆解

链接属性、作用域和存储期是三个维度。头文件声明接口，源文件提供一个外部定义；include guard 只阻止同编译单元重复包含。C/C++ 关于 tentative definition/inline 的规则不同，需要指定语言版本。

C++局部static的动态初始化通常在控制首次经过声明时进行，不能泛说全在main前完成；初始化线程安全不代表后续读改写安全。C++17 inline static成员可在类内定义初始化；const整型静态成员和constexpr成员还有版本/odr-use相关规则。静态成员函数可通过显式传入对象访问非静态成员，不能说它完全无法操作实例，只是没有隐式this。

## 例子与推演

```c
/* sensor.h */
extern int sensor_count;
/* sensor.c */
int sensor_count = 0;
static int internal_state;
```
不要在所有头文件中定义同一有初始化外部变量。

## 常见误区与失败边界

“static 永远放静态区”不说明链接和函数语义。“extern 永远不分配”在extern带定义时不成立。

## 面试追问

静态局部变量线程安全初始化是否等于后续操作安全？答：C++11起某些初始化有保证，但对象后续竞争仍需同步；C不能混用该结论。
