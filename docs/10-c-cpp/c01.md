# C01 · 数组、指针和长度为什么必须一起设计？

学习优先级：P0。先独立回答，再展开机制与验证。

## 直接回答

数组是连续元素组成的对象，指针是保存地址的对象。数组表达式在许多场合转换为首元素指针；这次转换不会携带数组长度。函数需要显式长度或有边界的视图。

## 原理拆解

sizeof 对真实数组得到总字节数，对形参中的 T a[] 得到指针大小，因为该参数声明被调整为 T*。指针运算只在同一数组对象及其尾后一位的允许范围内有定义；尾后指针可以用于比较结束，不能解引用。

## 例子与推演

```c
#include <stddef.h>
size_t count_positive(const int *a, size_t n) {
    size_t out = 0;
    for (size_t i = 0; i < n; ++i) out += a[i] > 0;
    return out;
}
```
调用方保证 a 指向至少 n 个 int；若 n 为 0，循环不会解引用 a。接口合同应写清楚是否允许空指针。

## 常见误区与失败边界

把 sizeof(a)/sizeof(a[0]) 放进接收数组的函数会得到错误长度。把结构体、另一个对象或内存映射寄存器误当同一数组跨界遍历也不成立。

## 面试追问

为什么 int ** 不等价于 int [3][4]？答：后者按整行布局，行指针的步长是 4 个 int；前者通常先解引用一个指针表。

## 动手练习与验收

用真实数组与指针分别打印 sizeof，解释差异；为长度 0、1、全负、全正写测试。验收：说明每次读取的合法范围，不依赖平台指针恰好为 4 字节。
