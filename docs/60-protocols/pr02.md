# PR02 · SPI 模式、片选与事务边界怎么核对？

学习优先级：P0。先独立回答，再展开机制与验证。

## 直接回答

SPI 常以时钟、MOSI、MISO 和片选连接，CPOL/CPHA 决定空闲电平和采样/改变边沿。没有统一的应用帧或自动 ACK，位序、字长、片选时序和 dummy 字节依设备数据手册。

## 原理拆解

四种模式必须按设备波形逐项核对，不只背模式编号。发送某字节时同时接收某字节，读设备常要先发送命令/地址再时钟出数据。片选连续性可能决定整次事务是否被识别。

## 例子与推演

读传感器：CS 拉低→发读命令→发地址→发送 dummy 同时读取 N 字节→等待传输真正完成→CS 拉高。DMA 完成与 SPI shift 完成需按控制器状态区别。

## 常见误区与失败边界

SPI 高速不意味着任意走线与负载都能工作；共享 MISO 还需要未选设备正确三态。本文是通用机制，具体时序必须引用器件规格。

## 面试追问

读值稳定但总错一位，先看什么？答：CPHA、采样边沿、bit order、时钟速度和逻辑分析仪解码配置。

## 动手练习与验收

画四模式的前两位，给每次事务列 setup/hold 等待点。验收：以真实器件数据手册为最终合同，不凭通用图套参数。
