# PR01 · I²C 起止、ACK、仲裁和时钟拉伸怎么理解？

学习优先级：P0。先独立回答，再展开机制与验证。

## 直接回答

I²C 常用开漏 SDA/SCL 与上拉；START/STOP 用 SCL 高期间 SDA 的规定变化标识，数据位通常在 SCL 低期间改变。ACK/NACK 是每字节的应答，仲裁和 clock stretching 处理共享总线与接收能力。

## 原理拆解

多个 controller 同时发送时，拉低占优势；发高却读低的一方可检测丢失仲裁。target 可能通过保持 SCL 低进行拉伸，但芯片/模式支持和超时需核对。7 位地址与包含 R/W 位的 8 位表示不同。

## 例子与推演

7 位地址 0x50 在写传输的地址字节为 0xA0，读为 0xA1；HAL 接口究竟要 7 位还是左移表示，查对应库。组合读可能用 repeated START 保持事务语义。

## 常见误区与失败边界

把 NACK 一律等于硬件坏了，忽略无设备、忙、结束读及错误地址表示。I²C 高电平由 RC 上升决定，不能只调 MCU 时钟。

## 面试追问

SDA 卡低怎么恢复？答：先确认电气与合法占用，按规范/设备要求做总线恢复并重初始化，避免盲目驱动冲突。

## 动手练习与验收

画 7 位地址写和寄存器组合读波形；验收：正确标 START、ACK、repeated START、NACK、STOP，并核对上拉。
