# PR10 · IP、MAC、子网掩码与 ARP 怎样串起来？

学习优先级：P0。先独立回答，再展开机制与验证。

## 直接回答

IPv4地址用于网络层寻址，MAC常用于本地链路交付。子网掩码决定目的是否在本地前缀；本地目的解析其链路地址，远端则先把帧交给适用下一跳网关。ARP用于以太网IPv4映射，不负责全网路由。

## 原理拆解

路由选择和邻居解析分工不同。跨路由时链路帧头会按链路变化，端到端IP则受转发/NAT等实际机制影响。ARP缓存过期/冲突和错误掩码可导致同一设备有时通有时不通。

## 例子与推演

设备192.168.1.10/24访问192.168.1.20，通常ARP目标；访问另一个网段则解析网关MAC，而不是在本链路寻找远方主机MAC。地址示例属于文档推演，真实配置需授权。

## 常见误区与失败边界

“MAC全程不变”“IP地址就是物理硬件身份”错误。IPv6不是直接继续用ARP，需另查邻居发现。

## 面试追问

两设备同网段却不通怎么查？答：链路、VLAN、掩码、ARP/重复IP、防火墙与服务各层独立证据。

## 动手练习与验收

手算三个目标是否同前缀并画下一跳。验收：区分IP目的与当前帧目的，不猜未知网络环境。
