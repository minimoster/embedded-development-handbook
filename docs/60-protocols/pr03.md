# PR03 · RS485 和 Modbus RTU 不是同一层东西？

学习优先级：P1。先独立回答，再展开机制与验证。

## 直接回答

RS485 主要定义差分电气传输，Modbus RTU 是常用于其上的协议。半双工 485 需要管理发送使能、总线占用和终端/偏置；RTU 还需要地址、功能、帧间隔与 CRC 等协议规则。

## 原理拆解

发送方向释放应在最后停止位真正发完后，而非仅内存 DMA 搬完。终端通常按总线拓扑末端安排，偏置与共模/隔离依板级设计。RTU 的时间判帧规则必须按波特率与规范，不把一次串口中断当帧。

## 例子与推演

控制 DE→启动发送→DMA 完成只表示 buffer 搬完→等待 UART TC→按设备时序释放 DE。超时应恢复接收并记录错误，避免一直占总线。

## 常见误区与失败边界

“RS485 自带地址/CRC”错误。串口多个设备连到一起不等于解决冲突，主站/请求响应时序需要协议。具体 Modbus 常量以官方规范核对，本仓库不猜参数。

## 面试追问

两节点正常，多节点不稳怎么定位？答：先电气拓扑/终端/地与方向，再帧间隔/地址冲突与重试。

## 动手练习与验收

设计半双工状态机，注入 DMA 完成但线路忙、响应超时。验收：任何错误路径都释放总线，不把物理层和协议层混讲。
