# DV09 · kmalloc、vmalloc 与 GFP 标志怎么选？

学习优先级：P0。先独立回答，再展开机制与验证。

## 直接回答

kmalloc常用于较小且需相应连续性条件的内核内存，vmalloc提供虚拟连续而不保证物理连续的映射。选择还取决于大小、上下文和设备需求；GFP标志说明是否允许等待/回收等行为。

## 原理拆解

GFP_KERNEL通常可睡眠，不能随意在原子/普通硬IRQ上下文使用。GFP_ATOMIC是受限分配选择而非永远成功保证。DMA使用独立DMA API，不能把任意kmalloc物理地址当所有设备可用地址。

## 例子与推演

将解析请求的可睡眠分配放到进程/work上下文，并检查NULL。高频路径预分配或池化，降低失败与延迟；卸载、取消与部分初始化失败配对释放。

## 常见误区与失败边界

“vmalloc更大所以更好”忽略映射和访问成本。“GFP_ATOMIC永不阻塞也永不失败”错误。不要用主机malloc行为推内核行为。

不要沿用旧2.6版本的 kmalloc 128KiB 或 DMA 4MiB实测数当通用上限。vmalloc是虚拟连续页映射模型，不能简单归为和小对象slab相同；page_address/kmap等页访问映射提供适用CPU虚拟地址，并非返回设备可用DMA地址。ioremap映射既有MMIO资源，不是新分配一块普通RAM。

## 面试追问

如何查内存泄漏？答：建立分配/释放拥有图，做错误路径注入，再用目标支持调试工具/测试验证。

## 动手练习与验收

为正常、失败、移除三路径列所有分配。验收：每块归属清楚，flags匹配上下文，未编译内核模块就不宣称已验证。
