# 41. 缺失的第一个正数（C++17）

> 普通数组 · HARD。前置：能读懂本题使用的容器与递归/循环状态。建议先手推，再自己写，最后看实现。

## 题意与接口边界

求数组中没有出现的最小正整数，要求线性时间、常数辅助空间；允许改变输入。

题目与完整输入约束：[官方题页](https://leetcode.cn/problems/first-missing-positive/)。本页为原创教学表达，不重复完整官方题面。

## 从朴素思路走向主解

长度n的数组最多占满1..n，答案必在1..n+1。把原数组当作大小n的桶：值x应放在下标x-1。负数、0、超过n的数不可能影响桶位，直接忽略。

## 状态与执行步骤

逐位置检查当前值是否在[1,n]且目标桶不是同值；满足就交换到目标位置，并继续检查换回的新值。归位后再扫描，首个nums[i]!=i+1的位置给答案；全对则n+1。

## 手推一组自建例子

[4,-1,1,2]：i0把4送到下标3，换回2；再把2送到1，换回-1停止。i2的1送到0。最终[1,2,-1,4]，下标2应为3却不是，答案3。

读到这里先暂停：不看代码，画出每次选择/指针移动后的状态；必须能解释为什么这一步安全，才算理解。

## 为什么正确

每次成功交换都把一个有效值放到正确桶，且以后不会把该桶正确值换走。重复值发现目标已经同值便停止，避免死循环。总成功交换不超过n，最后桶中是否正确恰好表示对应正整数是否出现。

## 完整 C++17 实现

源码：[可编译头文件](../../../algorithms/cpp/solutions/p0041_first_missing_positive.hpp)。本地包装的namespace用于把100题同时编译；在线平台提交时只保留类及所需标准头，链表/树节点以平台提供定义为准。

```cpp
#pragma once
#include "../support.hpp"

namespace hot100::p0041 {
class Solution {
public:
    int firstMissingPositive(std::vector<int>& nums) {
        const int n = static_cast<int>(nums.size());
        for (int i = 0; i < n; ++i) {
            while (nums[i] >= 1 && nums[i] <= n && nums[nums[i] - 1] != nums[i]) {
                int destination = nums[i] - 1;
                std::swap(nums[i], nums[destination]);
            }
        }
        for (int i = 0; i < n; ++i) if (nums[i] != i + 1) return i + 1;
        return n + 1;
    }
};
} // namespace hot100::p0041
```

## 复杂度与存储边界

时间 O(n)，额外空间 O(1)。虽然有while套for，每次交换永久增加已归位值数，成功交换总量线性；不含输出容器。

## C++与边界陷阱

必须先验证范围再访问nums[nums[i]-1]，C++的&&短路在此提供安全。目标桶等于当前值的检查防重复数无限交换。仅用if而不while可能漏掉换回的新有效值。

## 面试追问：先说变化，再改算法

不能修改输入时一般用集合O(n)空间；若输入可反复查询，排序并复用另有权衡。此“值映射桶位”模式也适用于找重复/缺失，但每个问题的值域与重复限制不同。
