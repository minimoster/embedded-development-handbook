# 15. 三数之和（C++17）

> 双指针 · MEDIUM。前置：能读懂本题使用的容器与递归/循环状态。建议先手推，再自己写，最后看实现。

## 题意与接口边界

输出和为0的不同值三元组，三个位置不能重复。答案按值去重，而不是按下标去重；本实现会排序并改变输入。

题目与完整输入约束：[官方题页](https://leetcode.cn/problems/3sum/)。本页为原创教学表达，不重复完整官方题面。

## 从朴素思路走向主解

三层枚举是 O(n³)。排序后固定最小位置i，把剩余部分变成有序两数和：和偏小移left，偏大移right。排序也让同值相邻，去重可直接跳过相邻值，无需set再过滤整份结果。

## 状态与执行步骤

排序；每个i若与前一个同值就跳过；双指针只在i右侧扫描。命中后记录三元组，跨过左右当前值的所有重复项。i的值已大于0时可以整体停止。

## 手推一组自建例子

[-3,-1,0,1,2,3]固定-3时，left=-1、right=3和=-1，左移到0得[-3,0,3]；再移动得到[-3,1,2]。固定-1得[-1,0,1]。重复0输入只能输出一次[0,0,0]。

读到这里先暂停：不看代码，画出每次选择/指针移动后的状态；必须能解释为什么这一步安全，才算理解。

## 为什么正确

排序保证和过小时，当前left配任何更小right都不可能达到0；和过大时当前right配任何更大left也不可能。i<left<right保证位置不同。跳过相同固定值与相同命中端值消除了同值组合的重复，而不漏新值组合。

## 完整 C++17 实现

源码：[可编译头文件](../../../algorithms/cpp/solutions/p0015_3sum.hpp)。本地包装的namespace用于把100题同时编译；在线平台提交时只保留类及所需标准头，链表/树节点以平台提供定义为准。

```cpp
#pragma once
#include "../support.hpp"

namespace hot100::p0015 {
class Solution {
public:
    std::vector<std::vector<int>> threeSum(std::vector<int>& nums) {
        std::sort(nums.begin(), nums.end());
        std::vector<std::vector<int>> answer;
        const int n = static_cast<int>(nums.size());
        for (int i = 0; i + 2 < n; ++i) {
            if (i && nums[i] == nums[i - 1]) continue;
            if (nums[i] > 0) break;
            int left = i + 1, right = n - 1;
            while (left < right) {
                long long sum = 0LL + nums[i] + nums[left] + nums[right];
                if (sum < 0) ++left;
                else if (sum > 0) --right;
                else {
                    answer.push_back({nums[i], nums[left], nums[right]});
                    int a = nums[left], b = nums[right];
                    while (left < right && nums[left] == a) ++left;
                    while (left < right && nums[right] == b) --right;
                }
            }
        }
        return answer;
    }
};
} // namespace hot100::p0015
```

## 复杂度与存储边界

排序 O(n log n)，双指针总 O(n²)。除答案外额外空间取决于 std::sort 的栈，一般 O(log n)；答案最坏 O(n²)，不能把输出空间写成常数。

## C++与边界陷阱

三个int相加需先提升long long。循环使用 i+2<n，避免 nums.size()-2 在短输入中无符号下溢。使用set去重会增加树容器成本，本课直接跳重，且对短输入也定义为空结果。

## 面试追问：先说变化，再改算法

若不允许修改输入，先复制数组并诚实增加 O(n)空间。推广 kSum 时，递归固定前缀并保留两数和底层，但需严谨处理重复与边界剪枝。
