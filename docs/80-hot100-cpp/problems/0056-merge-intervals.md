# 56. 合并区间（C++17）

> 普通数组 · MEDIUM。前置：能读懂本题使用的容器与递归/循环状态。建议先手推，再自己写，最后看实现。

## 题意与接口边界

合并闭区间中相交或端点相接的区间，输出两两不重叠的等价覆盖。本实现对区间按起点排序，因此改变输入。

题目与完整输入约束：[官方题页](https://leetcode.cn/problems/merge-intervals/)。本页为原创教学表达，不重复完整官方题面。

## 从朴素思路走向主解

无序状态下判断新区间该与谁合并很麻烦。按左端点排序后，已经处理的区间中只有最后一个合并段可能与当前区间重叠；更前面的段已与最后段隔开，且当前左端更靠右。

## 状态与执行步骤

按左端点、再右端点字典序排序；无结果或当前起点大于末段终点时开新段；否则延伸末段终点到两终点较大者，起点保持不变。

## 手推一组自建例子

[{5,8},{1,3},{3,6},{10,11}] 排成[1,3]、[3,6]、[5,8]、[10,11]。前三段通过相接/重叠延伸为[1,8]，最后因10>8新开[10,11]。

读到这里先暂停：不看代码，画出每次选择/指针移动后的状态；必须能解释为什么这一步安全，才算理解。

## 为什么正确

排序后当前左端不小于已处理左端。若与末段不相交，因其左端超过末段右端，更不可能与更早段相交；若相交，其并集仍是一个闭区间，更新右端覆盖全部点。归纳维护有序不重叠的精确覆盖。

## 完整 C++17 实现

源码：[可编译头文件](../../../algorithms/cpp/solutions/p0056_merge_intervals.hpp)。本地包装的namespace用于把100题同时编译；在线平台提交时只保留类及所需标准头，链表/树节点以平台提供定义为准。

```cpp
#pragma once
#include "../support.hpp"

namespace hot100::p0056 {
class Solution {
public:
    std::vector<std::vector<int>> merge(std::vector<std::vector<int>>& intervals) {
        std::sort(intervals.begin(), intervals.end());
        std::vector<std::vector<int>> answer;
        for (const auto& current : intervals) {
            if (answer.empty() || current[0] > answer.back()[1]) answer.push_back(current);
            else answer.back()[1] = std::max(answer.back()[1], current[1]);
        }
        return answer;
    }
};
} // namespace hot100::p0056
```

## 复杂度与存储边界

排序时间 O(n log n)，扫描O(n)。输出 O(n)空间，排序栈通常O(log n)；若把输出算入额外空间就是O(n)。

## C++与边界陷阱

闭区间端点相等要合并，判断开新段用>，不是>=。更新终点用max，不能直接取current[1]，否则包含区间会把大段缩小。每个输入区间需有两个合法端点，这不是对任意畸形vector的验证器。

## 面试追问：先说变化，再改算法

半开区间[a,b)在a==旧b时是否合并取决于期望表示，需明确边界语义。若输入已经按起点排序，可跳过排序降到线性；在线插入则需有序结构。
