# PJ02 · 怎样做一个 Linux 设备网关项目？

学习优先级：P0。先独立回答，再展开机制与验证。

## 直接回答

练习网关从串口/模拟数据源接收帧，经有界队列处理，再通过非阻塞 socket 输出；加入重连、背压和优雅退出。先主机 socketpair 测试，再交叉构建并在实际 Linux 设备部署。

## 原理拆解

分离协议解析、队列、I/O适配和业务状态，避免所有代码在一个循环里。每个 fd/线程/buffer 明确拥有者；解析器支持任意分片，网络发送支持短写和 EAGAIN，退出不等待永远不会来的事件。

## 例子与推演

交付：架构图、帧格式、线程/事件循环模型、配置示例、启动方式、故障注入、版本化构建。对网络断开明确丢弃/缓存/重试策略，记录 queue depth 和延迟。

## 常见误区与失败边界

声称“epoll 高并发”却没测公平预算和短写很容易被追问。练习用虚构设备/数据，不能把敏感连接配置放公共仓库。

## 面试追问

为何不用一个线程阻塞读写？答：小需求可以用，选择是容量/响应约束的权衡，不能只为了技术名词堆叠。

## 动手练习与验收

在主机注入断连、慢消费者、坏帧并退出；目标板补系统部署。验收：无泄漏/无无界队列/有限退出，指标有环境。
