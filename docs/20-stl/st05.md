# ST05 · 排序的比较器必须满足什么？

学习优先级：P1。先独立回答，再展开机制与验证。

## 直接回答

比较器要提供严格弱序。对相同元素返回 true、使用 <=、或依赖不断变化的外部状态都会破坏合同。稳定排序额外保证相等元素的相对顺序保留，但应按业务需要选择。

## 原理拆解

严格弱序要求 irreflexive 和 transitive 等性质。多字段排序通常按字典序比较，避免用 a-b 产生溢出。浮点 NaN 需要明确策略，因为普通比较并不能给所有值建立所需排序语义。

## 例子与推演

```cpp
struct Item { int priority; int sequence; };
bool less_item(const Item& a,const Item& b) {
    if (a.priority!=b.priority) return a.priority<b.priority;
    return a.sequence<b.sequence;
}
```
比较器不修改元素，也不做阻塞 I/O。

## 常见误区与失败边界

把“降序”写成 !(a<b) 会在相等时返回 true。排序前缓存传感器值，不能在比较器里每次重新读取会变化的设备寄存器。

## 面试追问

为什么返回 a.key-b.key 不合适？答：可能溢出且返回值被转为 bool，两个方向都可能 true。

## 动手练习与验收

检查 comp(x,x)==false；对小样本枚举传递性，并测相等/极值。验收：排序策略对并列键与 NaN（如存在）有明确规定。
