# ST06 · 复杂度、内存上界与实时性怎样一起讲？

学习优先级：P0。先独立回答，再展开机制与验证。

## 直接回答

渐进复杂度只说明规模增长，不直接给出实时截止时间。嵌入式选择算法要同时估算最大 N、分配、递归深度、cache、抢占和 I/O 等待，并用目标硬件测最坏路径。

## 原理拆解

O(N) 可能在小 N 上比 O(log N) 更快；平均复杂度不能替代 WCET。递归栈会叠加中断帧、局部对象和函数调用，桌面测试不代表 MCU 栈足够。时钟频率也不能直接换算所有指令耗时。

## 例子与推演

每 1 ms 处理最多 16 个样本，可设计固定上界循环。相同算法遇到输入 1600 个时应拒绝或拆批，不应静默破坏截止时间。保存可重复输入、编译配置与计时方法。

## 常见误区与失败边界

只给 Big-O 不够；只给平均耗时也不够。测量必须包括错误路径、最大帧和突发，不将优化级别不同的二进制直接比较。

图最短路还要说明负边、不可达点和距离累加的整数范围；若存在影响目标的可达负环，不能返回普通有限最短距离，应有明确检测与错误语义。

## 面试追问

如果任务偶发超时，如何区分算法慢与调度晚？答：分别记录就绪时间、开始时间、执行区间和阻塞区间。

## 动手练习与验收

为一个解析器列出最大输入、循环上界、栈预算和分配次数。验收：可解释最坏输入，并明确哪些时延还需硬件测量。
