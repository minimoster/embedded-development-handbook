# MC02 · 定时器频率、PWM 与时钟倍频怎么计算？

学习优先级：P0。先独立回答，再展开机制与验证。

## 直接回答

先确认定时器实际输入时钟，再用预分频与计数周期推导。边沿对齐向上计数常见 f_update=f_timer/((PSC+1)(ARR+1))，但中心对齐、重复计数器和不同模式会改变更新行为。

## 原理拆解

计数器按所选时钟递增，到达重装值产生指定事件；PSC 与 ARR 的寄存器值通常比计数个数少一。STM32 某些总线配置下定时器时钟与外设总线时钟关系特殊，不能总把 APB 频率直接代入。

## 例子与推演

若 f_timer=72 MHz，PSC=71、ARR=999，常见向上计数更新为 1 kHz。PWM 占空比取决于模式、极性、CCR 边界与计数方式；先用波形确认 0% 和 100% 的特殊设置。

## 常见误区与失败边界

“72 MHz CPU 所有定时器也是 72 MHz”错误。在线修改 PSC/ARR/CCR 若未考虑 preload 与更新事件，会出现半周期跳变。

## 面试追问

为何理论 1 kHz 示波器看到 500 Hz？答：检查中心对齐、翻转输出模式、时钟源和计数事件定义。

## 动手练习与验收

纸面计算三组参数并列时钟树依据；板测时记录周期、占空和更新时机。验收：计算说明模式，本仓库只做算术与主机测试。
