# MC05 · DMA 什么时候比中断逐字节更合适？

学习优先级：P0。先独立回答，再展开机制与验证。

## 直接回答

DMA 将传输工作从 CPU 搬运循环交给控制器，适合连续或较大数据量。CPU 仍负责配置、边界、错误与缓冲区管理；短小事务、复杂时序或不可达内存未必适用。

## 原理拆解

DMA 需要正确的源/目的、宽度、增量、方向、请求通道和内存区。完成中断通常表示该次搬运完成，不一定表示外设线路完全空闲，例如 UART 最后一个字节仍可能在移位寄存器。

## 例子与推演

发送缓冲区必须在 DMA 完成前保持有效且不被修改。栈上的临时数组启动异步 DMA 后立刻返回，会导致生命周期错误。双缓冲可让 CPU 处理一块时 DMA 填另一块，但交换责任需明确。

## 常见误区与失败边界

DMA 不是零成本，也不自动解决竞争。“DMA TC 就可关闭 RS485 发送使能”可能截断尾字节，应核对 UART 真正发送完成状态。

## 面试追问

为什么 DMA 向某 RAM 不工作？答：查总线可达性、内存域、cache、对齐和控制器限制。

## 动手练习与验收

画三阶段缓冲区所有权图：CPU 填充→DMA 使用→CPU 回收。验收：每次交换有具体事件，描述 TC 与线路 TC 差异。
