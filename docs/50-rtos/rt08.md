# RT08 · 任务栈、heap_1..heap_5 与内存预算怎么看？

学习优先级：P0。先独立回答，再展开机制与验证。

## 直接回答

任务栈与内核对象堆是不同预算。创建任务通常消耗 TCB 和栈，是否动态/静态由 API 配置决定。FreeRTOS 多种 heap 实现有不同释放、合并和多区域能力，要选定一种并固定版本。

## 原理拆解

例如 heap_1 不提供释放，适合只创建不删除；heap_4 支持合并相邻空闲块；heap_5 扩展到多个区域，初始化方式需核对。栈高水位是运行覆盖下的观测，不是形式最坏上界，FPU、深调用与 ISR 叠加要考虑。

## 例子与推演

任务 stack depth 的单位通常是 StackType_t 项，不应随口当字节；检查对应 port。每个任务记录高水位、最深路径、局部数组和格式化输出使用，主机栈不能代表 MCU。

## 常见误区与失败边界

“没溢出 hook 说明安全”错误，检测配置/触发时机有限。删除任务后内存回收路径和 idle task 进度也要了解。

## 面试追问

如何减少栈而不制造共享竞争？答：缩减局部大数组、专用缓冲池和受控拥有者，而非全部改成无锁全局变量。

## 动手练习与验收

列 TCB、各任务栈、队列、堆、DMA 区和保留区预算。验收：单位正确、有安全余量，动态峰值与失败路径可说明。
