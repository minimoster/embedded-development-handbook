# RT07 · 临界区、调度器挂起和中断屏蔽有什么不同？

学习优先级：P0。先独立回答，再展开机制与验证。

## 直接回答

临界区保护短小、特定范围内的并发交错；挂起调度器限制任务切换但不等于禁止 ISR；屏蔽中断影响响应延迟。选择必须匹配共享状态的所有访问者，不能拿一个机制替代所有同步。

## 原理拆解

若 ISR 与任务共享状态，只阻止任务调度仍挡不住 ISR。Cortex-M port 的临界区可能只屏蔽一部分可屏蔽中断，而非绝对关闭所有异常。嵌套和退出要匹配，长临界区会影响 tick 和设备事件。

## 例子与推演

更新“指针+长度”两个字段需要整体发布，消费者否则可能看到新指针旧长度。可用合适锁、临界区或发布不可变对象；根据消费者是否 ISR 决定允许机制。

## 常见误区与失败边界

在临界区里等待队列、打印串口或 delay 可能导致死锁或极大延迟。挂起调度器后仍需遵守内核 API 的限制。

## 面试追问

为什么临界区不能随便包整段驱动？答：硬件可能靠中断前进，包住等待会阻断完成事件。

## 动手练习与验收

对三个共享状态列全部读写者并选同步。验收：保护不变量、时长有上界、入口出口匹配且错误路径也释放。
